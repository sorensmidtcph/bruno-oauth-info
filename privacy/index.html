Privacy policy

Effective 30 September 2026

This policy covers Bruno, Søren Smidt's private Google Workspace automation.

Data the integration accesses

Bruno accesses only the Google accounts Søren connects. The requested permissions may include Gmail, Google Calendar, Google Drive and Google Docs.

How the data is used

Google user data is used to prepare calendar and email summaries, manage user-requested calendar availability, process accounting receipts, and save meeting notes in Google Drive. The integration may send an email, create a document or change a calendar event only as part of an automation configured by Søren.

Storage and security

OAuth credentials are stored in the macOS Keychain on Søren's computer. Working state for the automations is stored locally. Documents created by the integration remain in Søren's Google Drive.

Sharing

Google user data is not sold, used for advertising or shared with unrelated third parties. Data is sent to another service only when Søren has configured that action, such as sending a receipt to an accounting inbox or posting a private briefing to his own workspace.

Retention and deletion

Local automation state is kept only for as long as it is needed to operate the configured workflows and prevent duplicate actions. Søren can revoke Google access at any time in his Google Account and can delete local state or documents created in Google Drive.

Google API Services User Data Policy

Bruno's use and transfer of information received from Google APIs follows the Google API Services User Data Policy, including its Limited Use requirements.
